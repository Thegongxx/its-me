## 本轮观察到的问题与修正

1. 原扭曲带状 X 与过大的圆形控制抢占内容：改为清晰的金属分层字形，复位为交互后出现的文字按钮；旋转有边界，松开后归位，点击显示内部夹层。
2. 三章沿用同一种白底和对象：重构成封面、深色展陈、纸张桌面；对象在作品区之前退出并设为 inert，不阻挡项目链接。
3. 手机标题被桌面 flex 对齐推到右边：给作品/学习标题单独设置左对齐；关于页百分比 gap 在纵向布局不足，改为明确的像素间距。
4. 手机首屏对象提示靠近介绍：通过实际文字边界保留 50px 安全间距。320×667 下底部暂停/章节控件压到正文，暂停移到上方，章节导航在短屏隐藏。
5. 章节跳转与全局阅读页滚动偏移相叠加：首页独立设置 scroll-padding，标题由章节内留白避开固定导航；检查最终章节顶部为视口 0。
6. 旧首页样式产生层叠冲突：移除旧首页规则，分离场景样式与内页样式；纸张使用正向间距，避免摘要互相盖住。
7. 开发期间 Next.js 提示全局平滑滚动会影响路由切换：按当前版本文档增加 `data-scroll-behavior`。目录首张图改为 eager 加载；场景测量增加缺少目标节点时的保护。
8. 保留已修复的 Escape 关闭菜单并恢复焦点、Logo 回到 `#hello`、`/resume` 与 `/now` 的 308 跳转；没有重新引入独立简历或动态说明页。

本次模型在暂停后的两张间隔截图 SHA-256 完全相同。点击拆层、拖动不误触、方向键、Home 复位均实测，操作时页面保持 scrollY=0；恢复播放正常。实际在模型区域滚动可进入作品场景，手机菜单 Escape 关闭后焦点回到按钮。纵向触摸意图有单元测试，尚未在实体触屏测多点手势。

参考审阅：实际打开了 [Simon AKing](https://simonaking.com/) 的入口与导航形式；[donghao.ltd](https://www.donghao.ltd/) 在本次浏览器访问中因其脚本错误呈白屏，未声称看过完整效果。设计采用用户确认的全屏立体与滚动转场方向；未复制参考网站代码、模型或个人内容。

## 路由、SEO 与失败边界

- 公共主页面与详情、后台、状态 API、OG 图片正常响应。未知顶层路径返回 HTTP 404；未知详情显示 404 UI 和 noindex。Next.js 已开始 streaming 的详情请求可能返回 200，这是框架的状态码限制，并非成功内容。
- 本次生产构建启动后复查 14 个路径：11 个成功响应、两条旧路径 308、未知路径 404。正式版复验了对象点击/复位、手机菜单 Escape、作品入口、搜索无结果及恢复；本次正式版浏览期间未采集到控制台 warning/error。
- 实际操作了搜索无结果、前进后退、Markdown 预览、菜单打开/关闭、项目详情和页内锚点。观察到路由加载 skeleton；原始 `<script>` 在 Markdown 预览中被过滤，未执行。
- 示例模式管理员写入返回 503，跨源写入返回 403，设备上报返回 503，不接受测试遥测。
- 检查了页面标题、首页 canonical、站点地图/robots/OG 路由、安全响应头；示例模式 noindex，sitemap 不含示例成果，后台不索引。旧独立页不进入导航或 sitemap。
- 本机生产模式页面响应约 24–203ms（一次测量，含本机首次请求）；这不是公网性能或 Core Web Vitals 分数。WebGL 按需加载、DPR 上限、资源释放和后台停止已在源码审查。
