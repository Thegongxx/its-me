## 本轮观察到的问题与修正

1. X 只跟滚动旋转，缺少主动交互：新增对象范围内的拖动、点击展开/合拢、44px 复位按钮、键盘操作及可见提示。桌面实际拖动改变角度，拖动不误触展开。
2. 后两章转成侧面、难以辨认：各章默认角度保持正面轮廓，由访客控制完整旋转。
3. 手机雕塑过大、挤占正文：根据文字的实际高度计算剩余空间；字号与控制触点加大；空间不足时减少装饰。
4. 到达页尾被 footer 截断：用 Grid 叠层约束 sticky 场景，footer 移到场景之外。实际滚到页尾，雕塑、提示、复位与页脚均完整可见。
5. 菜单按钮聚焦时 Escape 无效：监听打开菜单期间的 Escape，关闭后焦点回到菜单按钮；生产构建复验通过。
6. 返回首页可能恢复到旧滚动位置：明确将站点 Logo、页脚和后台“查看网站”链接指向首页 `#hello`。
7. 旧简历/动态地址经渲染后才跳转：加上框架配置层 308 重定向，分别去 `/about`、`/#now`。

暂停后两张间隔截图的 SHA-256 完全相同；继续、复位、滚动仍可操作。原生键盘 Tab→Enter 展开、方向键旋转、Home 复位均实测，页面没有随这些按键改变滚动位置。手机纵向触摸识别有单元测试，浏览器滚轮在雕塑区域可以正常滚动；尚未在实体触屏上测多点手势。

## 路由、SEO 与失败边界

- 公共主页面与详情、后台、状态 API、OG 图片正常响应。未知顶层路径返回 HTTP 404；未知详情显示 404 UI 和 noindex。Next.js 已开始 streaming 的详情请求可能返回 200，这是框架的状态码限制，并非成功内容。
- 实际操作了搜索无结果、前进后退、Markdown 预览、菜单打开/关闭、项目详情和页内锚点。观察到路由加载 skeleton；原始 `<script>` 在 Markdown 预览中被过滤，未执行。
- 示例模式管理员写入返回 503，跨源写入返回 403，设备上报返回 503，不接受测试遥测。
- 检查了页面标题、首页 canonical、站点地图/robots/OG 路由、安全响应头；示例模式 noindex，sitemap 不含示例成果，后台不索引。旧独立页不进入导航或 sitemap。
- 本机生产模式页面响应约 24–203ms（一次测量，含本机首次请求）；这不是公网性能或 Core Web Vitals 分数。WebGL 按需加载、DPR 上限、资源释放和后台停止已在源码审查。
