## 发现的问题与实际修正

1. 旧界面的大 X、编号、拟物纸条和口号分散注意力：移除相关组件与 Three.js，改为作品封面与简洁索引。
2. 1280×720 首屏封面说明挤到底部提示：增加较矮桌面窗口规则。最终测量说明下缘约 638px，提示上缘约 665px，没有相交。
3. 平板首屏作品偏小、下方过空：单独调整 761–1000px 的封面尺寸、位置和展开幅度，复查 834×1112。
4. 转场淡出元素仍可能进入 Tab 顺序：淡出链接设为 inert；回到开场、手机尺寸和减少动态偏好恢复，实际 DOM 检查通过。
5. 次要文字对比不足：暖灰从 `#777168` 改为 `#6f695f`，相对米白从 4.25:1 提高至 4.78:1；暗红约 7.08:1，深色区次要文字约 6.82:1。这是主要色对计算，不是完整 WCAG 审计。
6. 开发预览提示首屏图片延迟加载：显式使用 eager，作品目录前两幅 eager、后续 lazy；首屏两个 SVG 资源复用。
7. 直接访问关于页时不能依赖首页 CSS：共享文字链接样式移到公共布局样式。
8. 分享预览图和图标沿用旧标识：同步重做，实际请求 OG 路由并查看生成图片。
