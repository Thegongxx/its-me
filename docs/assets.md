## Source and rendering

- All three active covers have intrinsic dimensions, a viewBox, title and description. They contain native SVG geometry and no scripts, foreignObject, bitmap images or remote dependencies.
- The current covers were parsed as XML and rendered in the website at desktop, tablet and phone sizes. Colours were revised for this design; their example status is unchanged.
- First-screen covers use eager loading. The two homepage images are reused from cache in the selected-work section. The third work-index image remains lazy loaded.
- The small FIELD NOTES label uses a common system font fallback; the large N is a native vector path.
- Fontsource packages for Instrument Serif, Manrope, Noto Sans SC and IBM Plex Mono are pinned. Licences remain in each installed package. No external font requests are required.
- The OG image loads the local Instrument Serif WOFF and is generated by Next.js. The favicon uses a simple X and burgundy dot.
- No reference-site code, model, portrait or project screenshot has been imported. Reference websites guide composition and interaction quality; no award is claimed.

For a personal release, replace the example covers with genuine project material through the existing admin editor. Unknown personal facts remain unfilled.
